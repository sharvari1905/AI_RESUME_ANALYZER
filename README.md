# AI Resume Analyzer

An AI-powered tool that analyzes resumes and gives an ATS (Applicant Tracking System) score, keyword matching, and improvement suggestions.

### Features
- Upload PDF resume and get instant ATS score
- NLP-based keyword extraction
- Skill gap analysis
- Job description matching

### Tech Stack
- Python, Streamlit, NLP, PyPDF2

### How to Run
pip install -r requirements.txt
streamlit run app.py
